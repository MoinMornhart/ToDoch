Installation

Proxmox – one command

In the Proxmox host shell (as root):

bash -c "$(curl -fsSL https://raw.githubusercontent.com/MoinMornhart/Todoch/main/ct/todoch.sh)"

The script asks for Default or Advanced, creates an unprivileged Debian 13 container (2 CPU · 2 GB RAM · 16 GB disk), installs Docker, generates all keys and starts ToDoch. At the end it prints the address and a one-time setup link for your account. The container's Proxmox console is accessible without a password.

Unattended, e.g. via SSH: var_ctid=108 var_hostname=todoch var_domain=todoch.example.com var_proxy=yes bash -c "$(curl …)" – all variables are listed in the README.

Updating

Type update in the container console. ToDoch backs up the database first, builds the new version, checks it and rolls back to the old one automatically if anything goes wrong.

Address and HTTPS

Passkeys only work over HTTPS with a fixed hostname. Three modes, switchable with one command:

CommandFits when …HTTPS is handled by …
todoch domain todoch.example.com --proxya reverse proxy sits in front (NetBird, Nginx Proxy Manager, Traefik)the proxy – ToDoch speaks HTTP on port 80
todoch domain todoch.home.arpaToDoch only runs in your home networkToDoch with its own CA
todoch domain todoch.example.com --acmethe domain points straight at the serverToDoch with Let's Encrypt

Reverse proxy: use http://<container-IP>:80 as the target – HTTP, not HTTPS. todoch info shows it at any time.

Administration inside the container

todoch infoAddress, mode, status of all services
todoch setup-codeShow the setup link again
todoch usersList users
todoch reset-password <email>New random password
todoch disable-2fa <email>Turn off two-factor when the authenticator app is gone
todoch backup / todoch restore <file>Back up and restore the database
todoch logs [app|web|db|worker]View logs

The keys for stored credentials are kept separately from the backup in /var/backups/todoch/keys/. Store both together in a safe place – no restore without the keys.

Docker Compose without Proxmox

git clone https://github.com/MoinMornhart/ToDoch.git && cd ToDoch cp .env.example deploy/.env && chmod 600 deploy/.env docker compose -f deploy/docker-compose.yml up -d --build

Fill in deploy/.env (every variable is explained), then open https://<TODOCH_DOMAIN>/setup#code=<TODOCH_SETUP_TOKEN>. ToDoch refuses to start if keys are missing, too short or still contain placeholders.
