Installation

Proxmox – ein Befehl

In der Shell des Proxmox-Hosts (als root):

bash -c "$(curl -fsSL https://raw.githubusercontent.com/MoinMornhart/Todoch/main/ct/todoch.sh)"

Das Skript fragt Standard oder Erweitert ab, erstellt einen unprivilegierten Debian-13-Container (2 CPU · 2 GB RAM · 16 GB Disk), installiert Docker, erzeugt alle Schlüssel und startet ToDoch. Am Ende stehen die Adresse und ein einmaliger Einrichtungslink für dein Konto. Die Proxmox-Konsole des Containers ist ohne Passwort zugänglich.

Ohne Rückfragen, z. B. per SSH: var_ctid=108 var_hostname=todoch var_domain=todoch.example.de var_proxy=yes bash -c "$(curl …)" – alle Variablen stehen in der README.

Aktualisieren

In der Container-Konsole update eingeben. ToDoch sichert vorher die Datenbank, baut die neue Version, prüft sie und springt bei einem Problem automatisch auf die alte zurück.

Adresse und HTTPS

Passkeys funktionieren nur über HTTPS mit festem Hostnamen. Drei Betriebsarten, umschaltbar mit einem Befehl:

BefehlPasst, wenn …HTTPS macht …
todoch domain todoch.example.de --proxyein Reverse-Proxy davor sitzt (NetBird, Nginx Proxy Manager, Traefik)der Proxy – ToDoch spricht HTTP auf Port 80
todoch domain todoch.home.arpaToDoch nur im Heimnetz läuftToDoch mit eigener CA
todoch domain todoch.example.de --acmedie Domain direkt auf den Server zeigtToDoch mit Let's Encrypt

Reverse-Proxy: Als Ziel http://<IP-des-Containers>:80 eintragen – HTTP, nicht HTTPS. todoch info zeigt es jederzeit an.

Verwaltung im Container

todoch infoAdresse, Betriebsart, Zustand aller Dienste
todoch setup-codeEinrichtungslink erneut anzeigen
todoch usersBenutzer auflisten
todoch reset-password <e-mail>Neues Zufallspasswort
todoch disable-2fa <e-mail>Zwei-Faktor abschalten, wenn die Authenticator-App fehlt
todoch backup / todoch restore <datei>Datenbank sichern und einspielen
todoch logs [app|web|db|worker]Protokolle ansehen

Die Schlüssel für gespeicherte Zugangsdaten liegen getrennt von der Sicherung unter /var/backups/todoch/keys/. Beides zusammen sicher aufbewahren – ohne Schlüssel keine Wiederherstellung.

Docker Compose ohne Proxmox

git clone https://github.com/MoinMornhart/ToDoch.git && cd ToDoch cp .env.example deploy/.env && chmod 600 deploy/.env docker compose -f deploy/docker-compose.yml up -d --build

Werte in deploy/.env eintragen (jede Variable ist erklärt), dann https://<TODOCH_DOMAIN>/setup#code=<TODOCH_SETUP_TOKEN> öffnen. ToDoch startet nicht, wenn Schlüssel fehlen, zu kurz sind oder Platzhalter enthalten.
